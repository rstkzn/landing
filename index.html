PROJECT 01REPLICATION / DATA MOVEMENT

Parallel initial load for PostgreSQL logical replication

Built an initial synchronization mechanism that parallelizes copying within individual tables, rather than being constrained to table-level concurrency. Parallelism is calculated from data volume; non-overlapping ranges are formed using mod(id, N), with streaming through psql and pipes instead of intermediate dumps.
